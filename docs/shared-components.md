# Shared components — index

**Status:** repo index, backing CLAUDE.md hard rule 9. Verified against `src/components/shared/` on 2026-10-07 (every file under `shared/` has its row).
**Last updated:** 2026-10-07 (`StockLevelPill` / `StockQuantityCell` moved to `components/warehouse/Stock/` on the served row flag, DR-41; owner decisions: `DateField` / `TimeField` on MUI X pickers, 25 / 50 / 100 pager, stock signs −/+, toggle filter cards (Payments, Debts), offline gate on the keyboard and on a device offline too, the header connection status, sidebar footer and 1440px collapse; earlier 2026-10-06 UI refresh)

**The rule:** before creating **any** component, scan this index. If a listed component (or a config of one) fits, use it. If a genuinely new shared component is needed, add its row **in the same commit**. When work consolidates onto a shared component, the superseded implementations are **deleted in the same change** — dead variants left in `shared/` are traps. **Every file under `src/components/shared/` must have an index row** — an unindexed shared file is a defect found in review. Module-local components stay in `components/<module>/` and are not listed — except shared items carrying a "Lives in …" location note and the promotion candidates at the bottom. Styling questions → `src/theme/` (`designTokens`, `chipTokens`, `iconSize`, `radius` — see design-tokens.md), never per-component hex.
